
## Lecciones tÃ©cnicas

- Un panel web que permite visualizar capturas de trÃ¡fico de red puede exponer credenciales en texto claro si el trÃ¡fico incluye protocolos no cifrados como FTP o Telnet.
- La reutilizaciÃ³n de credenciales entre servicios (FTP y SSH en este caso) amplifica el impacto de una fuga de credenciales.
- Las capacidades de Linux (`capabilities`) mal configuradas en binarios como Python pueden permitir escalada directa a root sin necesidad de exploit kernel.
- El uso de `cap_setuid` en un intÃ©rprete de Python permite invocar `os.setuid(0)` para obtener una shell con privilegios mÃ¡ximos.

## RemediaciÃ³n

1. Deshabilitar el acceso a capturas de trÃ¡fico histÃ³rico para usuarios no autorizados, o implementar cifrado obligatorio en servicios de transferencia de archivos.
2. Prohibir la reutilizaciÃ³n de contraseÃ±as entre servicios y forzar el uso de claves SSH en lugar de contraseÃ±as para acceso remoto.

4. Actualizar el sistema y aplicar principios de mÃ­nimo privilegio, eliminando capacidades innecesarias con `setcap -r /usr/bin/python3.8`.
